# ルイトAI AUTO TALK

APIを使わずにブラウザーだけで動く会議デモです。ChatGPT役とCopilot役が順番にデモ用の発言をし、Geminiは参加者一覧に「一時退出中」として表示されますが発言しません。

## 起動

`index.html` をブラウザーで開きます。会議スタートでテーマを入力すると、ChatGPT → Copilot の順に発言します。停止ボタンで中断できます。

会議ログは発言ごとにブラウザーの `localStorage` に保存され、ページを再読み込みしても復元されます。「ログを消去」で画面と保存データを消去し、「TXTで保存」でUTF-8のテキストファイルをダウンロードできます。保存データは同じブラウザー・同じサイト内に保持されます。

## GitHub Pages

リポジトリの **Settings → Pages** で、公開元に `main` ブランチの `/ (root)` を選んで保存してください。Pagesを有効にする前に、リポジトリが公開（public）であることと、内容をウェブ公開してよいことを確認してください。

## 注意

表示される発言はJavaScriptに書かれたサンプル文で、本物のAIではありません。APIキーをブラウザー側のコードや公開リポジトリに書かないでください。本物のAI APIに接続する段階では、安全にキーを保管するバックエンドが必要です。
